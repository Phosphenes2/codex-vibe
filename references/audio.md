# 打斗拟音与混音

拟音服务叙事、距离和材质。先做事件表，再选择采样或合成。拍点可以托住表演，接触音以画面可见的第一次碰触为准。背景音乐已经覆盖同一时刻的冲击时，可只补一层能听出材质的短声。

| 画面事件 | 声音设计 | 对齐点 |
| --- | --- | --- |
| 手臂或道具掠过 | 短气流，按方向少量声像移动 | 气流峰值略早于画面最快的掠过，接触前收低 |
| 布袖甩动 | 低音量的纤维摩擦 | 袖口开始加速或反向的一小段 |
| 道具相碰 | 木碰取干脆短声，金属用亮瞬态和短铃尾，瓷器用清细短响 | 首帧接触 |
| 人物摔落或重步 | 低频闷响配地面颗粒，远景收高频 | 身体或脚触地 |
| 盾牌或门扇承力 | 木声为主，按空间加短尾音 | 板面停止或产生可见位移 |
| 衣袍落定、余尘收束 | 布响或两三颗稀疏颗粒声 | 主响过后留空，再让细节入场 |
| 印章落字 | 短纸声或闷木声 | 印章接触纸面，避开正在说的字 |

一处重点接触以一个主材质为核心，按需要叠一层低频或落地反应。快节奏段可减掉重复脚步和挥动。声像根据镜头位置轻偏，距离主要靠音量、高频和空间尾声表现。安静镜头保留风、水声、衣摆或原混音里已有的环境声。试听重拍前后、两次连续接触和过渡到对白的段落。

## 参考混音与换音乐

- 精确复刻且使用成片混音时，保留起点与声画对应关系。兼容封装且无需重切波形时可直接复制音频流。单独添加拟音是另一种混音版本，按需要处理重叠音色。
- 独立配乐先按选段裁切，预留尾音。用旁白、配乐、拟音三个独立轨做试听。话音期间可减轻音乐和拟音压力；用户要求配乐电平固定时，先从拟音和旁白轨调整。大幅增加监听音量来听细节后，再回到正常音量听一次。
- 校验采样率、声道、片长、样本峰值和编码后的真峰值。面向常规平台可把 −1 dBTP 当作峰值上限的起点，最终按交付平台和用户要求校核。查看 `ffmpeg -hide_banner -i out.mp4 -af ebur128=peak=true -f null -` 的 Summary；超标时回到混音轨调整，再重新编码。

## 可运行的拟音样例

Python 需 NumPy，配乐读取使用 FFmpeg。把事件 JSON 绑定到分镜事件时间，下面的例子是一段编排测试。

```json
{
  "fps": 30,
  "frames": 120,
  "seed": 21,
  "events": [
    {"frame": 22, "cue": "cloth", "level_db": -25, "pan": -0.2},
    {"frame": 27, "cue": "whoosh", "level_db": -20, "pan": -0.15},
    {"frame": 33, "cue": "metal", "level_db": -17, "pan": 0.1},
    {"time": 2.02, "cue": "step", "level_db": -22, "pan": 0.22},
    {"frame": 84, "cue": "wood", "level_db": -19}
  ]
}
```

```shell
python scripts/foley_mix.py cues.json --sfx-out sfx.wav --music bgm.wav --music-start 0 --mix-out mix.wav
```

脚本合成 48 kHz 双声道的 `cloth`、`whoosh`、`metal`、`wood`、`ceramic`、`step`、`impact`、`stamp`。每个事件使用一个 `frame` 或 `time`，`pan` 范围 −1 到 1，`level_db` 为素材峰值相对满幅的电平。气流有起伏，短碰撞从事件起点起音。需要试听拟音轨时仅传 `--sfx-out`。需要配乐加拟音时传 `--music` 与 `--mix-out`。传入配乐须覆盖成片长度，可在脚本外裁好乐句、做淡出或准备合成配乐。

混音默认按样本峰值约 −1.5 dBFS 留余量，必要时统一降低拟音电平，保留配乐增益设定。需要显式预调配乐电平时传 `--music-gain-db`。旁白通过单独的时间线合成，最终导出后再测真峰值。
