# 皮影视觉与生图人物

现成人物、空景与四区部件表提示词在 [可复制的生图提示词](puppet-prompts.md)。韩信样片实际使用同一套生成头片和衣身贯穿远近景。袖、手、碗和杖由 Canvas 配合轨迹绘制。

## 锁定角色再出部件

1. 写一份角色表。保存正面偏侧的近景与全身造型，标出发髻、下颌、肩线、眼神方向、衣领、腰扣和服饰的左右特征。有参考片时用清楚的眼部与发式近景，加一张看得见下摆的全身参考。
2. 生图时输出同一角色的透明头片、无袖衣身和需要独立移动的配件。手若要持物或指点，可做手势变体；多姿态共享头片、衣料和锚点。左右向差异明显时各定一张脸，反向移动时保留配饰所在侧。
3. 检查真实 alpha，清除透明边缘污色，标记头片旋转中心、左右肩、手腕、脚底及道具握点。把关节装进同一个角色局部坐标。肩缝用衣袖覆盖叠接处，布纹和描边在接缝处统一。眼皮、嘴形和发饰可按需设独立层。
4. 做构图小样，检查脸从远景到特写的比例、目光、亮度和纹理。正式渲染前让每个角色至少演一次跨镜头的转头、抬手或递物。留存最终提示词、人物透明素材及锚点。

空景以冷蓝灰的环境色、黑剪影屋脊和暗金局部背光为基础。把门扇、旗、前树及遮挡物单独成层。衣袍尽量留哑光，近景突出布纤维和面部切面，留出正文、身份和引文的位置。
