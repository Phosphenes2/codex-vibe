# 逐帧逆向

用原始显示顺序编帧号，第一帧记为 0。可变帧率素材优先使用显示时间戳。记录片源尺寸、帧率、实际时长、声音类型和选段起点。候选切点与逐帧表可交给 [rea-video](https://github.com/JuneYaooo/rea-video) 的镜头模块，脚本需要 FFmpeg、ffprobe 以及可导入的 rea-video、NumPy、OpenCV。已安装项目时可省略 `--rea-root`。

```shell
python scripts/frame_scan.py reference.mp4 --out scan --rea-root /path/to/rea-video
```

- 在每个候选切点前后检查脸、屋脊、地平线和文字。全屏提亮而构图区分度低时，连续看后续帧辨别场内闪光、渐隐和闪白入镜。
- 先在屋檐、墙角等静物上估计镜头位移与缩放，再分别拟合头、躯干的变换。手腕和道具轨迹换算到躯干局部坐标。选起势、极值、落点、保持和收势，跨遮挡重新设锚。
- 分开测接触和反应。例如门扇用固定扫描线的遮挡宽度拟合，递碗同时看碗沿、掌心和肘部。文字显隐用位置和颜色验证，闪白盖过的帧检查前后位置。
- 若复用静态空景，从底景移除人物、文字和道具，检查屋檐接缝和残影；记录哪些像素来自参考、哪些由代码重绘。
- 用同一帧号对照参考与样片，复核构图、切点和动作走势。没有作者工程时，给出可观察的事实和实现推断。原片混音中的音乐、旁白及拟音无法由混音直接确认各自来源时，按可测事件标记。
