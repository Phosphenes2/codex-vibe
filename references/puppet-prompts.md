# 暗金皮影历史短片 · 生图提示词

每次制作先复制「固定画风」，再加「人物模板」或「空景模板」。换角色时只替换方括号里的内容。有角色近景和全身参考时，把两张图一起给模型。

## 固定画风

```text
二维中式皮影剪纸动画，秦汉历史叙事。人物是平面皮影偶，近正面或浅三分之二侧脸，轮廓干净，形体由简洁几何切面组成。五官精简但可辨识，用细眉、眼白、小瞳孔和清楚的下颌线表现神态。肤色温赭，以少量硬边色块交代鼻梁和面颊的明暗。衣料哑光，保留细布纤维和淡淡暗纹。人物边缘贴一圈细而克制的暗金或浅赭轮廓光，主色为墨黑、炭褐、低饱和青灰，米白与旧金只用在衣领、发簪和扣件等小面积细节。整体像灯幕后用操杆演出的剪纸戏偶。避免真人摄影感、日漫大眼、立体塑胶质感、高饱和金属反光和厚重描边。
```

## 通用人物模板

```text
为二维关节动画生成同一个角色的透明 PNG 部件表。

人物为［时代、身份、年龄］。脸型［下颌和颧骨特征］，眼神［神态］，肤色［颜色］。发式［发髻或冠帽］，固定配件［形状、颜色和位置］。穿［主色、面料、衣领形状、腰带及扣件］。头部朝画面［左或右］轻微侧转，双眼可见。按参考图保持脸型、发式、衣领和腰扣特征贯穿各镜头。

画面上半区放独立头片，从发顶到下颌，完整保留发簪。下半区放无袖衣身，从肩线到下摆，包含交领、腰带和裙裾；留出肩关节接入位置。两个部件独立，四周有足够透明留白，无重叠和裁边。双臂、手、道具另行制作。带真实 alpha 透明通道，无地面、投影、文字、边框和参考线。光线平整，人物受光可在合成时统一处理。
```

## 韩信与漂母 · 可直接追加的人物描述

**韩信｜秦末淮阴布衣**

```text
秦末年轻男子韩信，身形清瘦，窄下颌，浅暖赭肤色，斜挑浓眉，杏眼留米白眼白和小黑瞳，薄唇收住表情。面部微向画面右侧。黑发收成紧实高髻，髻基有一道细箍和一支水平的细金簪，耳侧留短而平的黑鬓。穿炭褐麻布交领长袍，米白窄 V 领，单道深色斜襟，黑腰带与小长方铜扣。裙裾直垂、略外张，下段近墨黑，带一条很淡的下摆接缝。
```

**漂母｜秦末淮阴洗衣老妇**

```text
秦末年长洗衣妇，脸型略长收颌，暖棕肤色，细灰眉，窄杏眼留少量米白眼白，眼角有轻微纹理，神情温厚而严肃。面部微向画面左侧。灰发拢成偏宽的圆髻，深青灰发带压住额前细碎灰发，一根直铜木簪从左往右微抬。穿低饱和深青灰交领袍，内领米白，一道较宽的灰赭色斜襟，深腰带，方铜扣内嵌哑光青绿。裙身近墨青，下摆略外张，衣料带很淡的菱形暗纹。
```

两人共用一张部件表时，在末尾加上这段布局指令。

```text
正方形透明画布，左上韩信的头片，右上漂母的头片，左下韩信的无袖衣身，右下漂母的无袖衣身。四件素材各自完整，约占所在分区的七到八成，中央分隔留白，不相触、不跨区。
```

## 空景模板

```text
16:9 横屏二维皮影戏空景，［时代与地点］，［夜色或黄昏］。前景是一层近黑地面或贴边树影，中景预留宽阔的表演区域，远景以黑色翘檐屋脊和低缓山影叠出层次。天空采用低饱和蓝灰与黯暖琥珀渐层，薄云横向延伸，水面或地面泛冷灰微光。仅在［月光、门洞或天际］布置一处集中的暖色背光。轻颗粒与柔和暗角，背景细节柔化。留下容纳字幕的底部空间。画面里无人物、文字、水印或分镜边框。
```

做近景和远景时复用同一套透明头片与衣身。用代码完成镜头推拉、关节摆动、递物和衣袖运动，并在合成时统一冷暖、阴影和轮廓光。
