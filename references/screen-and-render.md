# 动画、屏幕效果与验收

## 分层和配合

绘制顺序通常为远景与背光、场景中层、人物与道具、局部碰撞与尘粒、前景遮挡、颗粒及暗角，最后是字幕和信息标签。画内效果和相机用同一个世界坐标。右上身份、左上年代地点、底部字幕用屏幕坐标。闪白期间若正文需要可读，让正文位于闪光之上；复刻原片时按实测遮罩顺序执行。

| 场面 | 画面动作 | 文字与声音 |
| --- | --- | --- |
| 沉静对话 | 轻微推近，头身分开做迟滞，目光回到对手 | 台词先可读，停顿时可留环境音 |
| 道具改变处境 | 位移、遮挡、接触和光量同源驱动 | 接触用拟音，短句或关键词对应语义重音 |
| 身份揭示 | 一次硬切、聚光或暖白切入，保留人物表情 | 突出身份词；大字和身份标签留出编号或出处空间 |
| 戏剧性碰撞 | 瞬间用局部尘粒、碎屑或很短的相机冲量，随后回稳 | 主材质瞬态踩接触帧，字幕基线稳定 |
| 历史引文 | 金色竖排逐列显现，边缘保持轻薄 | 出处另设小字；不同时挤入一组身份条和长字幕 |

风格基础是蓝灰环境光与局部暗金暖光，灰黑前景和软化远景给人物让位。静镜可用布景视差和稀疏尘粒制造呼吸感。重场面选一种主要屏幕效果；同一个重拍的闪白、震屏、火星和音效由同一事件决定启用项。控制全屏闪变的强度、频次和持续帧数。短促减速或停顿要在动作极值附近验看，给观众留下看清楚接触与反应的时间。

韩信前段用关门遮光、暖白切近景、金字逐列和红章作为画面语法，实测见 [韩信样片](han-xin-opening.md)。打斗声和接触特效是后续场景的制作方法。十秒样片使用参考同期混音。

## 确定性渲染

- 以 `draw(t)` 接收成片时间，镜头、姿态、字幕、光效依赖同一份事件表。种子随机用于尘埃和颗粒。等待图层与字体加载完再跑无头浏览器。以 `frame / fps` 逐帧导出，录制实时窗口时另行检查重复帧与丢帧。
- 取首帧、切点前后、接触瞬间、动作极值、字幕最长和最后一帧。用户指定九帧和两轮修订时按要求执行。近景核对眼神与肩颈，快动作查穿插、屏幕方向和剪影，内嵌字幕查安全区和碰撞。
- 动作段做连续慢放，再按正常速度加声音回看。需要验证参考同步时输出同帧左右对照。实际可播放文件导出为 H.264 + AAC，帧率、尺寸和总时长按项目规格。

```shell
ffmpeg -framerate 30 -i frames/%06d.jpg -i mix.wav -map 0:v:0 -map 1:a:0 -c:v libx264 -crf 17 -pix_fmt yuv420p -c:a aac -b:a 192k -movflags +faststart output.mp4
ffprobe -v error -count_frames -show_entries stream=codec_name,width,height,avg_frame_rate,nb_read_frames,duration -of json output.mp4
```

按实际文件编号改图像序列模式。入参应按帧数校准音轨时长。编码后重查开场、切点、画面结束和音轨尾音。交付成片、分镜事件表和用户需要的源码素材包；说明生成与借用素材、声音来源和实际观察到的差异。
